# Assets

| Folder | Contents |
|---|---|
| `textures/` | planet, sun, moon and sky maps used by the 3D view (bundled with the app) |
| `icons/` | application icon (`icon.ico`; `icon.png` / `icon.icns` are generated and not tracked) |
| `gallery/` | screenshots shown in the project README |
| `installer/` | generated installer wizard artwork (not tracked) |
| `reference/sky/` | extra Milky Way / star maps kept for future use (not bundled with the app) |

Planet textures: Solar System Scope 2k maps, CC BY 4.0 (<https://www.solarsystemscope.com/textures/>). The licence of the files in `reference/sky/` still has to be recorded before they ship.
