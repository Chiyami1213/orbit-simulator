Quick start

  1. Open Modules in the left menu and pick a module (for example Lambert Transfer).
  2. Choose a homework or exam problem from Load a homework / exam problem, or type your own values. Sliders and number boxes accept exact values.
  3. The results table, the 3D animation and the annotated 2D figure update as you type. Press Solve & Draw to force an update.
  4. Use the Export Figure tab to save PNG, PDF, 3D page, Python or MATLAB files.
  5. Enter your name under Settings → Figure Title: it is printed in every figure title.

The three modes

  • Solve: the twelve course modules and the reference tools in the left menu.
  • Sandbox: The Add library on the left holds bodies and spacecraft; click one to add it on an orbit about the selected body. Click a body in the view to open its panel on the right (Basic, Motion, Orbit, Forces, Actions). The bar along the bottom has play, reverse, the date and a time-warp slider, and the view, background, more and action tools. Changes re-run the simulation from the current time; undo and redo are under the lightning-bolt button.
  • Design: resources, a command sequence, numerical propagation and GMAT script import / export (see below).

Tutorial

A short guided tour starts the first time you open the program. Run it again any time from Help → Start Tutorial, from Settings → Help, or with F1. Esc leaves it.

Mission workspace

  • Resources hold spacecraft, propagators, burns, coordinate systems, report files and views (GMAT names are used throughout). Editing a Cartesian state updates the Keplerian one and the other way round.
  • Sequence is the command list. A Propagate command stops at the first of its stop conditions, for example Sat.Earth.Periapsis, Sat.Earth.TA = 120, Sat.ElapsedDays = 2.
  • Run Mission shows a progress bar; Plots, Reports and Compare show the results. Compare sets the exact course answer against the propagation as built.
  • GMAT Script shows the exported .script. Import… reads GMAT scripts (a subset) and saved .orbitmission files; anything unsupported is listed.
  • Every module result has Open in Mission and an Export button for a GMAT script. Settings → Conventions switches between the default and GMAT way of showing results.
  • Maneuver Planner (under the space view on the Plots tab): choose a point on the trajectory, set the burn with the Prograde, Normal and Radial sliders, see the predicted path and the orbit before and after, then Insert Node Into Sequence splits the propagation there and adds the burn.
  • Trajectories can be saved as CSV, CCSDS OEM, or (with the optional spiceypy package: pip install spiceypy) as an SPK kernel with a Cosmographia catalogue. The catalogue follows Cosmographia's catalogue format but has not been opened in Cosmographia by the program's author.
  • Settings → Ephemeris and GMAT: built-in ephemeris or the JPL DE440s kernel (downloaded only when you press the button), and the folder of an installed GMAT.

Where your files are saved

Everything the program writes on your computer goes to %APPDATA%\OrbSim\ and is never uploaded:

settings.jsonyour settings
screenshots\pictures saved with F2
exports\figures and scripts saved from the Export Figure tab
logs\error log, useful when reporting an issue

Uninstalling the program leaves this folder in place, so your settings survive a reinstall.

Tips

  • Drag a panel by its ⠿ grip onto another panel (left, right, top, bottom, or the centre to swap) or onto a window edge to move it. Drag the gaps between panels to resize them. If the window gets too small the panels stack and scroll. Settings → Layout resets the arrangement.
  • The Test Cases page re-runs every homework and exam problem against the printed answers.
  • Choose light, dark or your device setting under Settings → Appearance.
