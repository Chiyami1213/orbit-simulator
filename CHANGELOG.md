# Changelog

New changes go above this line, newest first.

## Unreleased

- **Interface style shared with PropSim:** five color themes (Graphite, Ocean, Forest, Plum, Light; F10), flat widgets, menu bar File / Edit / View / Design / Analysis / Help, Preferences (F9), Ctrl+R to solve, F12 to reset the panels, Ctrl+Q to quit with an optional confirmation, a busy bar for exports and backups, American spelling and APA title case in the interface.

## 1.0.0

- **Solve mode:** twelve course modules (N-body accelerations, two-body constants, state and conic conversions, Kepler propagation with f and g, hyperbolic flyby, elements and 3-D state, single-impulse maneuver, Hohmann and bi-elliptic transfers, plane change, patched conics, gravity assist, Lambert) with step-by-step tables, homework-style 2-D figures and an interactive 3-D animation.
- **Export:** figures as PNG or PDF, a standalone 3-D page, and Python (matplotlib) or MATLAB scripts that redraw the plots; LaTeX labels in figures and exports.
- **Homework presets and test cases:** problems with printed answers load as presets, and the Test Cases page compares computed and printed values.
- **Design mode:** GMAT-style missions (spacecraft, coordinate systems, propagators, impulsive burns, reports, command sequence), numerical propagation with Verner RK 8(9), Prince-Dormand 7(8) and 4(5) or the exact Kepler solution, optional J2, solar radiation pressure and drag, a patched-conic model, reference trajectory import, porkchop plots and a maneuver planner.
- **GMAT compatibility:** export of module results and missions as GMAT R2022a scripts, import of a subset of scripts, and an optional comparison run in an installed GMAT.
- **Sandbox mode:** a live N-body sandbox with ready-made scenes, an Add library with placement preview, an object panel, undo and redo, saved scenes, time warp in both directions and Send to Design.
- **Ephemerides and textures:** a built-in offline ephemeris or the JPL DE440s kernel (downloaded on request); built-in 2K planet textures and optional 8K downloads.
- **Interface:** light, dark and device appearance, five color themes, rebindable keys, movable and closable panels, a menu bar, a shared main menu, a guided tutorial, backup and restore of user data, and built-in issue reporting.
- **Conventions:** results can be shown in the default way or the GMAT way; the numbers and presets do not change.
- **Packaging:** a Windows installer and a macOS disk image build.
